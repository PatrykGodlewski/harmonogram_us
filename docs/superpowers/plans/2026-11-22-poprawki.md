## Decisions

- **Stands (ruling, not fixed):**
  - `getEventById` reads event links in a separate query: it runs in parallel with the others and is a primary-key lookup; adding the column to `queryEvents` would load jsonb for every list row.
  - Widget SSR session lookup / no cache header: in a cross-site iframe the browser sends no session cookie (SameSite=Lax), so the lookup ends without a database read; a public cache header is unsafe while the root route dehydrates the signed-in user into the HTML of a direct visit.
  - Effective-end filter scans published public events: at campus scale (thousands of rows) it costs milliseconds; an index needs a stored end column kept in step with the programme — not worth it before it shows in metrics.
  - Proxy body limit: hosting configuration, not code; documented in `docs/development.md`.
- Upload in progress: the storage key is recorded in `stored_file_deletions` before the PUT and removed in the same transaction that inserts the row. The worker deletes only keys older than 1 hour (`STORED_FILE_GRACE_MS`), so a crash at any point leaves at most one key, removed later.
- Event links change by single atomic operations (append; remove index *i* only if it still holds that link), so two editors never overwrite each other; a lost race just refreshes. Limit 30 → `EVENT_LINKS_LIMIT`.
- Survey text answers are shown only from 3 responses (`SURVEY_TEXT_MIN_RESPONSES`), so a lone respondent's words are not attributable. `REGISTRATION_RETENTION_DAYS` must be ≥ 30 (the survey window).
- Rating questions show anchors: 1 = „bardzo źle” / "very poor", 5 = „bardzo dobrze” / "very good".
- Pages opened from a personal token link (survey, withdraw) send no Referer (`<meta name="referrer" content="no-referrer">`).
- A signed-out visitor following a file link of a signed-in-only event is sent to sign in and back to the file.
- Teams: no meeting for a cancelled (`EVENT_CANCELLED`) or ended (`EVENT_ENDED`) event; failure logs add Graph's error `code` (letters, digits, `._-`, ≤ 64 chars), never the body; the button says „Tworzenie spotkania…” with `aria-busy` while waiting.

## Review Focus
